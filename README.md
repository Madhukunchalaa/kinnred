# Kinnred Landing Page

People. Nearby. On your wavelength. A premium location-based social discovery landing page with an interactive app simulator and radar map.

## Features

- **Interactive Wavelength Radar Map**: Float and orbit nearby user profiles with active sonar sweep animations.
- **Interactive Phone Simulator**: Demo the live Grid view, category filters, request acceptance and photo unblur flow, circles, and privacy lock controls.
- **Onboarding Wizard Profile Builder**: Real-time waitlist onboarding form that updates a mock MySpace card preview.
- **Interactive Safety Sandbox**: Click to simulate request acceptance and real-time profile unblurring.

## Running Locally

To run the local server:
```bash
node serve.js
```
Then navigate to `http://localhost:4599` in your web browser.
